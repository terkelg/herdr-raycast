# Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Manage Agents command: flat searchable agent list with brand icons, breadcrumbs, and a status and kind filter; open in terminal, prompt with history and clipboard paste, live output, rename, explain state, copy pane id, close pane, and start another agent.
- Dashboard command: workspaces, tabs, panes, and agents with counts, activity dots, focus and copy id actions, plus rename and close for workspaces, tabs, and panes.
- Focus Attention Agent command: jump to the agent that needs you, blocked first, then done.
- Agent Status menu bar command: blocked plus done count on a background refresh, macOS notifications when an agent newly needs attention, click to focus.
- Typed NDJSON socket client with session discovery, ping and protocol check, pane-id targeting, focus fallbacks, and graceful offline handling.
